📝Введение в itertools

Библиотека itertools предоставляет мощные функции для работы с комбинаторикой в Python. Эти функции часто используются в задачах ЕГЭ для перебора различных комбинаций и перестановок элементов.

💡 Основной модуль: 
from itertools import product, combinations, permutations, combinations_with_replacement

Все функции возвращают итератор, поэтому для получения результатов часто используется list() или цикл for.

🎯product() - Декартово произведение

Описание

Возвращает декартово произведение множеств — все возможные комбинации элементов при повторении.

Синтаксис: 
product(множество, [repeat=кол_во_повторений_множества])

Примеры использования

Пример 1: product('ABCD', repeat=2)

from itertools import product

result = list(product('ABCD', repeat=2))
print(result)

Результат:

('A', 'A') ('A', 'B') ('A', 'C') ('A', 'D') ('B', 'A') ('B', 'B') ('B', 'C') ('B', 'D') ('C', 'A') ('C', 'B') ('C', 'C') ('C', 'D') ('D', 'A') ('D', 'B') ('D', 'C') ('D', 'D')

Всего: 4² = 16 комбинаций

⚠️ Важно: При repeat=n функция генерирует n-й декартов квадрат множества. Элементы повторяются!

Когда использовать

  • Перебор всех возможных комбинаций с повторениями (например, двоичные числа)
  • Вложенные циклы: for x in range(2): for y in range(2): ... → product(range(2), repeat=2)
  • Анализ всех возможных состояний в логических функциях

🎯permutations() - Перестановки

Описание

Возвращает все перестановки элементов — все способы расставить элементы в разном порядке без повторений.

Синтаксис: 
permutations(множество, [длина_элемента])

Примеры использования

Пример 1: permutations('ABCD', 2)

from itertools import permutations

result = list(permutations('ABCD', 2))
print(result)

Результат:

('A', 'B') ('A', 'C') ('A', 'D') ('B', 'A') ('B', 'C') ('B', 'D') ('C', 'A') ('C', 'B') ('C', 'D') ('D', 'A') ('D', 'B') ('D', 'C')

Всего: A₄² = 4·3 = 12 перестановок

Пример 2: permutations('ABC')

Без указания длины = все элементы:

from itertools import permutations

result = list(permutations('ABC'))
print(result)

Результат:

('A', 'B', 'C') ('A', 'C', 'B') ('B', 'A', 'C') ('B', 'C', 'A') ('C', 'A', 'B') ('C', 'B', 'A')

Всего: 3! = 6 перестановок

⚠️ Важно: Каждый элемент используется только один раз в каждой перестановке! Порядок имеет значение.

Когда использовать

  • Поиск соответствия переменных в логических функциях (Тема 2)
  • Поиск соответствия между графом и таблицей (Тема 1)
  • Расстановка элементов в определённом порядке

🎯combinations() - Комбинации

Описание

Возвращает все комбинации элементов — все способы выбрать элементы без повторений и без учёта порядка.

Синтаксис: 
combinations(множество, длина)

Примеры использования

Пример 1: combinations('ABCD', 2)

from itertools import combinations

result = list(combinations('ABCD', 2))
print(result)

Результат:

('A', 'B') ('A', 'C') ('A', 'D') ('B', 'C') ('B', 'D') ('C', 'D')

Всего: C₄² = 6 комбинаций

⚠️ Важно:
  • Без повторений: AB и BA — это одна комбинация, не две
  • Всегда отсортированы: Элементы выводятся в лексикографическом порядке
  • AB и BA — это разные перестановки, но одна комбинация!

Когда использовать

  • Выбор подмножеств элементов
  • Выбор команды из людей (порядок не важен)
  • Анализ всех пар или троек элементов

🎯combinations_with_replacement() - Комбинации с повторениями

Описание

Похожа на обычный combinations(), но значения в элементах могут повторяться. Всё ещё без учёта порядка.

Синтаксис: 
combinations_with_replacement(множество, длина_элемента)

Примеры использования

Пример: combinations_with_replacement('ABCD', 2)

from itertools import combinations_with_replacement

result = list(combinations_with_replacement('ABCD', 2))
print(result)

Результат:

('A', 'A') ('A', 'B') ('A', 'C') ('A', 'D') ('B', 'B') ('B', 'C') ('B', 'D') ('C', 'C') ('C', 'D') ('D', 'D')

Всего: 10 комбинаций (включая AA, BB, CC, DD)

💡 Сравнение:
  • combinations('ABCD', 2): AB, AC, AD, BC, BD, CD (6 штук)
  • combinations_with_replacement('ABCD', 2): Добавляются AA, BB, CC, DD (10 штук)

Когда использовать

  • Выбор с повторениями (например, выбор билетов, где можно взять несколько одинаковых)
  • Расчёт мультимножеств

⚖️Сравнение всех функций

Функция Полный результат (повторяющиеся пары) Кол-во Порядок Повторения
product('ABCD', repeat=2) AA AB AC AD BA BB BC BD CA CB CC CD DA DB DC DD 4² = 16 Важен ✓ Есть ✓
permutations('ABCD', 2) AB AC AD BA BC BD CA CB CD DA DB DC A₄² = 12 Важен ✓ Нет
combinations('ABCD', 2) AB AC AD BC BD CD C₄² = 6 Не важен Нет
combinations_with_replacement('ABCD', 2) AA AB AC AD BB BC BD CC CD DD H₄² = 10 Не важен Есть ✓

Шпаргалка для выбора функции

❓ Как выбрать функцию:
  • Порядок важен + повторения? → product()
  • Порядок важен + без повторений? → permutations()
  • Порядок не важен + без повторений? → combinations()
  • Порядок не важен + повторения? → combinations_with_replacement()

Примеры использования в ЕГЭ задачах

Тема 1: Поиск соответствия между графом и таблицей

from itertools import permutations

for p in permutations('ABCDEFGH'):  # Все способы расставить переменные
    # проверяем соответствие
    pass

Тема 2: Логические функции и таблицы истинности

from itertools import product, permutations

for a0, a1, a2 in product((0, 1), repeat=3):  # Все комбинации неизвестных
    for x, y, z in permutations((0, 1, 2)):    # Все перестановки переменных
        # проверяем условие
        pass
